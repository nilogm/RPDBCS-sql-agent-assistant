## LLM-Based Text-to-SQL Agent Software Assistant for ESP Fault Diagnosis Aid in the Oil Industry

This repository contains information regarding the dataset, prompts and tools used in the paper "LLM-Based Text-to-SQL Agent Software Assistant for ESP Fault Diagnosis Aid in the Oil Industry".

All information cannot be made publicly available as it is currently being used in a private software.

Prompts require sensitive information such as the database schema and private domain information.

Files:
 - `agent_prompt.md` presents the prompt given by the core agent in the system.
 - `check_schema_tool.py` presents the `Check Schema` tool code.
 - `in_scope_dataset_github_version.json` presents the question templates used in the experiments. Not all templates were used, as a sampling method was applied.
 - `judge_prompt_in_scope.md` contains the prompt used by the judges to evaluate the In-scope questions.
 - `judge_prompt_out_of_scope.md` contains the prompt used by the judges to evaluate the Out-of-scope questions.
 - `out_of_scope_github_version.json` presents the Out-of-scope dataset used to assess the system.
